# frontend

当前前端是一个不需要Node.js构建的原生网页/PWA，文件位于`web/`。启动后端后访问 <http://127.0.0.1:8000> 即可使用。

## 用户可以做什么

- 手机调用后置摄像头拍照，或从相册/电脑文件中选择图片。
- 电脑端把图片拖放到图片输入区域。
- 预览图片、核对文件名和大小、清除后重新选择。
- 选择环境概述、文字读取、物品查找或视觉追问任务。
- 查看画面质量、真实能力状态、警告、结构化证据和耗时。
- 使用浏览器语音朗读后端返回的播报文案。
- 在支持的浏览器中安装到主屏幕，并在新版本可用时主动更新。

前端不会生成模拟识别结果。后端会逐项显示检测、OCR和视觉理解的真实配置状态；当前视觉理解可通过GLM-4.5V API启用，检测和独立OCR未配置时仍会明确提示。

## 文件作用

| 文件 | 作用 |
|---|---|
| `index.html` | 页面语义结构、表单、状态区和无障碍播报区 |
| `styles.css` | 桌面/手机布局、高对比度、键盘焦点和减少动画适配 |
| `app.js` | 选图校验、预览、API请求、超时、语音、安装和网络状态 |
| `manifest.webmanifest` | 应用名称、图标、启动方式和任务快捷入口 |
| `service-worker.js` | 缓存静态应用外壳、发现新版本，明确跳过所有API请求 |
| `icons/app-icon.svg` | PWA、浏览器页签和主屏图标 |

## PWA与隐私边界

Service Worker只缓存HTML、CSS、JavaScript、Manifest和图标。`/api/`请求、用户图片和分析结果永远直接访问网络，不写入Cache Storage。断网时可以打开页面外壳，但页面会明确说明分析服务不可达。

修改前端静态文件准备发布时，要同时提升`service-worker.js`中的`CACHE_NAME`，否则已安装用户可能继续看到旧资源。

摄像头和PWA安装通常需要HTTPS安全上下文；`localhost`是本地开发例外。真机联调不能只把电脑的`127.0.0.1`地址发给手机，应使用同一局域网可访问的HTTPS地址。

## 手工验收

1. 桌面选择一张合法图片，确认预览、分析、结果聚焦和语音按钮正常。
2. 390×844手机视口检查无横向滚动，拍照和相册入口可触摸。
3. 上传非图片、空文件、超大图片时，应在请求前或后端明确拒绝。
4. 切断网络后刷新，确认页面外壳可打开、分析不可用提示清楚、旧结果不会出现。
5. 恢复网络，确认服务状态自动恢复。
6. 发布新缓存版本，确认“更新网页”出现并能完成Worker切换和刷新。
