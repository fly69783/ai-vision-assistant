# 比赛交付检查清单

## 代码和运行

- [ ] 源代码可从全新目录安装并启动。
- [ ] 依赖版本、Python版本和运行命令准确。
- [ ] 连续完成3次现场演示，不崩溃。
- [ ] 准备离线视频、依赖包、模型和文档备份。

## 技术证据

- [ ] 系统架构图与实际目录一致。
- [ ] 每个“创新点”都有对照实验。
- [ ] 指标附测试集、计算方法和原始表格。
- [ ] 至少整理3类真实失败案例和修复前后对照。
- [ ] 没有把基础框架测试写成模型准确率。

## 规则和来源

- [ ] 最终比赛通知和允许的AI工具清单已核对。
- [ ] 模型、API、代码库和数据集全部登记在`LICENSES.md`。
- [ ] 报名表如实披露AI工具和生成内容。
- [ ] 所有演示素材有合法来源，不包含不必要的个人信息。

## 用户和安全

- [ ] 明确说明没有真实视障用户参与，不虚构访谈和评价。
- [ ] 不做蒙眼行走、上下楼梯、过马路或避障实验。
- [ ] 演示和文档明确“辅助理解，不替代专业导航设备”。
- [ ] 低置信、超时、断网、低光和模糊都有明确提示。

## 最终材料

- [ ] 设计说明书。
- [ ] 用户手册。
- [ ] 3—5分钟演示视频。
- [ ] 答辩PPT和问题库。
- [ ] 测试报告、原始数据和失败案例。
- [ ] 第三方来源与许可证清单。
